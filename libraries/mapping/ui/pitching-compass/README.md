# @carma-mapping/ui-pitching-compass

Pitching compass UI components for both Cesium and Leaflet/MapLibre map engines.

## Components

### CesiumPitchingCompass
Interactive pitching compass for Cesium 3D maps with mouse drag controls.

### LibrePitchingCompass
Interactive pitching compass for MapLibre/Leaflet 2D maps with mouse drag controls.

### CompassNeedleSVG
Shared compass needle SVG component.
