# @carma-cesium/selections

Visualizes selections from `SelectionProvider` as 3D markers in Cesium.

## Overview

- Forwards selections from `SelectionProvider` to Cesium
- Displays 3D markers for active selections
- Point features use `CesiumModel` component
- Area features visualization (TODO)
