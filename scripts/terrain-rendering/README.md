# Terrain rendering probes

- [`verify-displaced-terrain.mjs`](./verify-displaced-terrain.mjs): offline prepared ECEF mesh versus texture-displaced instances, using the production sun/shadow fit. Requires installed Chrome and repository dependencies. Run `node scripts/terrain-rendering/verify-displaced-terrain.mjs [output-directory]` from the checkout. Add `--shared-runtime` to exercise Geoportal’s shared runtime path, Lambert material and projected map textures. Writes a side-by-side PNG and JSON for shadow-off/on and two camera pitches. HTTP requests are blocked; no terrain tiles are downloaded. The GPU comparison permits at most 0.1% pixels differing by more than one 8-bit channel level, and rejects shader/page errors and repeated unchanged uploads. This is a rasterization tolerance, not permission to change source geometry or quality targets.
